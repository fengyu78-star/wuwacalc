# 鸣算屋 · 鸣潮配队伤害计算器

这是鸣算屋计算器的**非商业源码公开版**，供学习、研究、修改及非商业分享。正式站：[wuwacalc.cn](https://wuwacalc.cn/)。本仓库的本地运行版本不提供正式站账号服务。

## 运行

安装 [Node.js](https://nodejs.org/) 22或更高版本，在仓库目录打开终端：

```powershell
npm run setup
npm start
```

然后打开 **http://127.0.0.1:8765/**，点击“游客访问”。首次setup会按固定清单从正式站下载约数百MB的图片、字体及本地OCR运行资源。需要网络；之后相同文件会按哈希复用。中断后重跑即可。无需安装npm依赖，也无需填写任何密钥。

源码ZIP不含大体积运行资源。未完成setup时可以阅读代码，页面中的图片及部分导出/OCR功能会缺失。不要用双击index.html的方式运行。

## 本版范围

- 保留公开版本的角色、武器、声骸数据、配队配置、技能轴、Buff和计算代码，以及本地保存、JSON导入导出。
- 不提供账号、云端保存、在线方案库、榜单投稿、库街区在线接口或AI识图中转；相关界面可能仍显示入口，但本地接口明确返回不可用。
- 浏览器的外部网络连接默认受本地服务器策略限制。图片和用户填写的AI密钥不会被本地服务器转发。
- 个别依赖外链的图像会被拦截并显示占位；不影响计算及JSON方案文件的读写。
- 本地方案保存在浏览器中；不同端口/浏览器是不同存档空间。请用文件导出备份。
- 服务仅监听本机地址。自行对外部署属于另一个工作项，需要独立配置后端、权限、素材授权和隐私说明。
